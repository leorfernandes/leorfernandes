## 🎯 What I Bring

These are the principles behind every test I write and every bug I report.

- **Reliability over coverage** — a passing suite that hides flaky tests is worse than no suite at all.
- **Documentation as a deliverable** — a bug without reproduction steps isn't a bug report, it's a rumor.
- **User behavior-informed testing** — knowing *why* users do unexpected things helps me find edge cases before they do.
